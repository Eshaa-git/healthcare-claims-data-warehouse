# Data and secrets

Use only documented public synthetic inputs and locally generated fixtures. Do not upload patient,
employer, client or proprietary data. Commit .env.example with empty credentials, never .env.
Bind local services to loopback; cloud demos require authentication and encrypted connections.
Logs and screenshots must not expose secrets. Optional external LLM use is restricted to synthetic
notes and a configured budget. This repository makes no regulatory-compliance claim.
