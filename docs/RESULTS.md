## Summary

Built a batch pipeline using Python, PostgreSQL, dbt and Airflow in Docker on a local M1 Mac.
It loaded 55,916 synthetic Medicare claim and drug-event rows for a 1,000-beneficiary cohort and
reconciled 38/38 row and payment checks to the cent. When a load failure was injected, nothing
partial was committed or published, and the next run recovered by reloading only the failed file.
